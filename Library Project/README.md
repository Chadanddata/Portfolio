

This is a project I completed in Python that will allow you to upload a csv file containing book information that will build a library with the data. It will organize the books by genre 
and place the books virtually on the correct shelf and let you know if a book can not be placed due to shelf size or if the genre doesnt exist.




v2 of this project should include an input function that allows a person to add books to an existing library and make changes to the library if new genres are added. It should also allow
